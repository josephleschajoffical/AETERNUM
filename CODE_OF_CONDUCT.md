# Codice di condotta / Code of Conduct

## Il nostro impegno / Our pledge

Vogliamo un progetto accogliente e rispettoso per tutti, a qualsiasi livello di esperienza.
We want a welcoming and respectful project for everyone, at any experience level.

## Comportamenti attesi / Expected behavior

- Rispetto e pazienza, soprattutto verso i nuovi / Be respectful and patient, especially with newcomers
- Critiche costruttive, date e ricevute / Give and accept constructive feedback
- Pensare al bene del progetto e degli utenti / Focus on what is best for the project and its users
- Presumere la buona fede / Assume good faith

## Comportamenti inaccettabili / Unacceptable behavior

- Molestie, insulti, minacce, attacchi personali / Harassment, insults, threats, personal attacks
- Linguaggio o immagini discriminatori / Discriminatory language or imagery
- Pubblicare dati privati altrui / Publishing others' private information
- Usare il progetto per accessi non autorizzati a sistemi / Using the project for unauthorized access to systems

## Applicazione / Enforcement

I maintainer possono modificare o rimuovere commenti, chiudere issue e pull request, e bloccare chi viola le regole.
Per segnalare un problema usa la segnalazione privata di GitHub o contatta il maintainer dal suo profilo. Le segnalazioni sono trattate in privato.
Maintainers may edit or remove comments, close issues and pull requests, and block people who break these rules. Reports are handled privately.
