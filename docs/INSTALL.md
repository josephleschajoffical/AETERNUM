# Provare Aeternum Security OS / Try it

1. Scarica l'ISO (link sul sito) e controlla l'impronta con il file `.sha256`.
2. Scrivila su una chiavetta USB con **Rufus** in modalità **DD Image**, oppure copiala su una chiavetta **Ventoy**.
3. Avvia il PC dalla chiavetta in modalità **UEFI** (Secure Boot spento).
4. Accesso automatico al desktop. Utente `admin`, password `admin`.
5. Per installare sul disco: icona **Installa Aeternum** sul desktop. **Cancella il disco scelto.**

> Provala prima in una macchina virtuale o su un PC di prova.
