# Politica di sicurezza / Security Policy

## Versioni supportate / Supported versions

Aeternum Security OS è alla **prima versione (1.0)**. Riceve correzioni solo l'ultima versione pubblicata.
Aeternum Security OS is at its **first version (1.0)**. Only the latest published version receives fixes.

| Versione / Version | Supportata / Supported |
| --- | --- |
| 1.0 | ✅ |

## Segnalare una vulnerabilità / Reporting a vulnerability

**Non aprire una issue pubblica** per problemi di sicurezza.
Please **do not open a public issue** for security problems.

Usa la segnalazione privata di GitHub: scheda **Security** del repository → **Report a vulnerability**. Descrivi:
Use GitHub private reporting: **Security** tab → **Report a vulnerability**. Describe:

- cosa è coinvolto e come riprodurlo / what is affected and how to reproduce it
- l'impatto previsto / the impact you expect
- una possibile correzione, se ce l'hai / a suggested fix, if any

Riceverai una risposta appena possibile. Ti chiediamo un tempo ragionevole per correggere prima di divulgare.
You will get a reply as soon as possible. Please allow reasonable time to fix before disclosing.

## Ambito / Scope

Questa politica copre il codice e la documentazione di questo repository. Per problemi in FreeBSD o nei pacchetti di terze parti, scrivi direttamente a quei progetti.
This policy covers code and documentation in this repository. For problems in FreeBSD or third-party packages, report to those projects directly.
