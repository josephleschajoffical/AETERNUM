AETERNUM

SECURITY OS
RESILIENT • DEFENSIVE • HARDENED

Sistema operativo per la sicurezza informatica basato su FreeBSD 15.1 (amd64), con desktop XFCE, firewall attivo e strumenti di sicurezza preinstallati. Progetto open source, licenza BSD.

Versione 1.0, prima versione. Le lingue aggiuntive e l'antivirus non sono ancora disponibili. Usalo su un computer di prova o da chiavetta.
⬇ Scarica l'ISO (circa 3 GB)

Il download parte direttamente, senza account. Il file è un archivio ZIP con l'immagine .iso e il file .sha256. Prima va estratto sul computer.

Come usarlo

  1. Estrai lo ZIP e ottieni il file .iso.
  2. Scrivilo su una chiavetta USB (almeno 8 GB) con Rufus, scegliendo la modalità Immagine DD. Il contenuto della chiavetta viene cancellato.
  3. Avvia il PC dalla chiavetta in modalità UEFI (di solito F12, F10, Esc o F2 all'accensione). Se non parte, disattiva Secure Boot.
  4. Entra con utente admin e password admin (solo per prova: cambiala).

Installazione sul disco

Dal desktop live usa l'icona Installa Aeternum Security OS. Funziona su PC UEFI e cancella il disco scelto. Questa funzione è sperimentale.

Verifica del file

Confronta lo SHA256 del file .iso con quello nel file .sha256 dentro lo ZIP.
